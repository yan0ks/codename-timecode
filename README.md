# Codename «Timecode»

Учебный сервис на Go для отбора фрагментов видео. Зритель предлагает
отрезок, редактор рассматривает заявку. Одобренные фрагменты появляются
на общей шкале видео.

## Команда

- yan0ks — видео, заявки, модерация и веб-страница.
- Александр — вход, выход, сессии и проверка прав доступа.
