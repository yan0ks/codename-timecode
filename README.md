# Codename «Timecode»

Учебный сервис на Go для отбора фрагментов видео. Зритель предлагает
отрезок, редактор рассматривает заявку. Одобренные фрагменты появляются
на общей шкале видео.

## Команда

- yan0ks — видео, заявки, модерация и веб-страница.
- Александр — вход, выход, сессии и проверка прав доступа.

## Локальный запуск

Нужен Go 1.22 или новее. Из корня репозитория запусти сервер:

```sh
go run ./cmd/timecode
```

В другом терминале проверь, что он отвечает:

```sh
curl -i http://localhost:8080/health
```

В Windows PowerShell используй `curl.exe`. Ожидаемый ответ — `200 OK` с телом `ok`.
